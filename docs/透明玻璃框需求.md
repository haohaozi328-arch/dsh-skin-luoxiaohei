# 透明玻璃框需求（AI 内容加框）

> 皮肤：dsh-skin-luoxiaohei
> 目标：给 AI 生成的内容加「透明玻璃框」，从森林背景中清晰区分出来。

---

## 一、要加框的元素（对照真实会话流）

AI 生成的每一块内容，都要有框：

| 块 | 真实示例 | 说明 |
|---|---|---|
| 上下文注入 | `@deepseek-ai/dsh-system-prompt` | 系统提示注入 |
| 上下文注入 | `skill-catalog` | 技能目录注入 |
| Think | `The user just said "你好"...` | AI 思考过程（可展开/收缩） |
| AI 正文 | `你好！我是运行在 DeepSeek Harness...` | markdown 回答文字 |
| 工具调用 | Search / Read / Write / Edit / Pwsh | 工具执行块 |

---

## 二、框的构成

每块外面一个框，框由三部分组成：

1. **边框线**：一条线围住这一块
2. **透明玻璃**：框内半透明背景 + 毛玻璃模糊（`backdrop-filter: blur`）
3. **渐变**：多色渐变底色（绿 → 金 → 酸绿 → 米白，避开蓝紫）

---

## 三、当前实现状态

| 元素 | 选择器锚点 | 状态 |
|---|---|---|
| 工具块（含 Think/上下文注入） | `div:has(> [data-disclosure-row])` | 透明框 + 静态渐变 + 淡白边框 |
| AI 正文 | `[class*="gshEtW_body"]:not(:has([class*="l5Ng6a"]))` | 透明框 + 淡白边框 |
| 用户提问 | `[class*="_userStack"] > [class*="_bubble"]` | 透明框 + 淡白边框 |

---

## 四、待确认项

1. **框的粒度**
   - (a) 每块单独一个框（上下文注入 ×2、Think、正文、工具各自成框）
   - (b) 一整轮 AI 回答合成一个大框

2. **边框线样式**
   - (a) 淡白线（当前）
   - (b) 明显可见的线（绿 / 白 / 灰，待定色）

3. **渐变**
   - (a) 静态多色渐变（当前）
   - (b) 流动变色动画（`dshGlassFlow` 18s 缓慢流动）

---

## 五、约束

- 只改皮肤 CSS，不动产品 DOM 结构
- 停用即完全还原（清理契约）
- 避开蓝紫渐变
- 不影响现有功能（开闭原则）
